# 红黄绿

> 纯文字 · 多人联机 · 悬疑推理 · 阵营对抗 · 线索争夺

6–10 人在一张 13 个节点的地图里搜集红黄绿三种线索，用「公开会」把证据钉到别人身上，
或被别人钉死。侦探要把凶手全部淘汰，凶手要把侦探全部淘汰——而你还有一个别人不知道的个人目标。

**没有画面**：没有 3D 场景、没有小地图、没有语音。战斗和搜证都是「输入指令 → 读一段结算文本」。

```
————————————————————————————————————————
体力 3/3 · 位置：案发现场甲 · 正常
红标 0/3 · 通缉 0 · 信誉 100 · 线索 红0 黄1 绿1
武器 电击器 · 剩余 5 次
指令> 搜证
>>> 你蹲下来，开始看这些不该存在的东西。（3 秒）
你找到一枚 9mm 弹壳，余温尚存。地面有被擦拭过的血迹。
获得【黄线索·弹壳】来源：案发现场甲 · 指向：孙某 · 可疑证据
```

## 特性

- **三种线索，三种玩法**：红色直接计红标；黄色两两组合升红；绿色可抗辩、可挂保护
- **红标即生命**：3 个公开红标直接淘汰；抗辩用「反证强度 ≥ 致命度」判定
- **暴力有代价**：通缉值 0–100，NPC 警察只惩罚暴力行为，被捕掉线索、第四次被捕出局
- **无倒计时**：没有总局时钟，节奏由线索保底、悬案压力、区域热点、强制收束推动
- **双层胜负**：团队胜负之外，每人还有一个独立判定的个人目标
- **纯文字联机**：HTTP + SSE，房间码开局，四频道文字聊天（区域 / 公开会 / 阵营 / 幽灵）
- **零依赖**：没有 npm 包，Node ≥ 18 直接跑

## 快速开始

```bash
git clone <this-repo> && cd honghuanglv
npm start                 # 联机服务器 → http://127.0.0.1:8787
npm run play              # 单机：你 + 7 个机器人
npm run watch             # 观战：全机器人打一局
npm test                  # 37 项测试（16 规则 + 21 联机）
```

浏览器打开 `http://127.0.0.1:8787`，建房拿到房间号，其他人填同一房间号加入，
不足 6 人由机器人补位。

## 部署到 Railway

仓库已就绪，**无需任何配置**：

1. Railway → **New Project → Deploy from GitHub repo** → 选这个仓库
2. Railway 自动识别 Node 项目，执行 `npm install`（无依赖，秒过）与 `npm start`
3. **Settings → Networking → Generate Domain** 拿到公网地址
4. 配置项已写好，不用手填：

| 项 | 值 | 位置 |
| --- | --- | --- |
| 启动命令 | `node mvp/src/net/server.js` | `railway.json` |
| 健康检查 | `/healthz` | `railway.json` |
| 端口 | 读 `process.env.PORT`（Railway 自动注入） | `src/net/server.js` |
| 监听地址 | `0.0.0.0` | 同上 |

**注意**

- 房间数据在**单进程内存**里，不要开多副本（Scale 保持 1），否则玩家会落到不同实例。
- 免费实例空闲会休眠，第一次访问需要等几秒冷启动。
- SSE 连接靠每 15 秒的 ping 保活，Railway 的边缘代理支持长连接。

## 设计要点

- **事件日志自带可见性范围**（global / node / near / private），每个玩家只收到自己该看到的
  事件。文字版的「视野」和聊天频道的权限都由这一层统一保证，不是散落各处的 if。
- **交互统一抽象成 `ctx.ask(player, spec)`**：机器人同步应答、命令行阻塞读、联机挂起等
  `POST /api/answer`。同一套引擎因此能跑单机、观战、批量模拟和联机。
- **平衡来自实测**：全机器人对局跑了几百局后，发现「保护可无限续」「黄升红凑不出对」
  「残局无新证据」三个会让对局永不收敛的洞，补丁记录在规则文档 §C.3。

## 平衡现状（每档 10 局全机器人）

| 人数 | 凶手 | 侦探 / 凶手 / 平 | 平均时长 |
| --- | --- | --- | --- |
| 6 | 1 | 9 / 1 / 0 | 22 分 |
| 7 | 2 | 3 / 7 / 0 | 56 分 |
| **8** | **2** | **5 / 4 / 1** | **50 分** |
| **9** | **2** | **5 / 4 / 1** | **49 分** |
| 10 | 2 | 9 / 1 / 0 | 39 分 |

8–9 人双凶手是唯一接近 50/50 的配置。机器人不会谈判，真人局的胜率会不一样。

## 已知限制

- 掉线重连不会回到原来的待回应提示
- 只有文字频道，没有语音与私聊
- token 走明文 HTTP，目前适合朋友局，不适合公开运营
- 机器人不会协作谈判（看不出「我们一起指他」）
